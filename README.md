# 司序·知所先后

校园通知与个人任务规划项目，由第7组课程作品「口述行动链」升级。主名「司序」，辅名「知所先后」。

当前前端保留原有Dify对话入口与独立API样例演示；可编辑任务、个人时间表和确认后重算将在后续阶段接入，尚不能把这些目标写成已完成功能。

## 本地预览

在本目录运行 `python -m http.server 8080`，打开 `http://127.0.0.1:8080`。现有 `api-config.js` 仍配置原有Render API，点击API演示会请求该服务；只浏览命名预览不会提交个人任务。

## 开发约定

产品主线与确认过的命名见 `PRODUCT.md`，工作区来源见上级 `SOURCE_MANIFEST.json`。历史报告与原始DSL保留旧名称，以便复核原作。根目录Git为源码快照建立的本地版本记录，不等于原仓库完整历史。
