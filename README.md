# 司序·知所先后

校园通知与个人任务规划项目，由第7组课程作品「口述行动链」升级。当前本地工作台已提供通知候选、逐项确认、原文依据、真实空闲、剩余时间与修改后重算；模型提取经本地代理接入独立Dify Workflow，旧版Dify对话保留为独立辅助入口。公开GitHub Pages/Render未发布本轮改动。

## 本地预览

本目录运行 `../.venv/bin/python -m http.server 8873 --bind 127.0.0.1`，在浏览器打开 `http://127.0.0.1:8873`；后端目录运行 `../.venv/bin/python -m campus_agent.server`，默认8765。前端在localhost自动选择8765，网页不自动发送原文，点击提取、补全时间或检查时主动提交相应数据。新前端先验证服务的snapshot_v2能力，不会退回旧服务算法。模型服务的隐藏密钥启动方法见父目录reports中的Dify接入说明，默认不自动启用。

原文时间缺少年份时，在左侧选择通知参照日，再在已有草稿旁点击“按参照日期补全原文时间”；动作调用已有规则接口，不再次调用模型，仅补全有唯一原文依据的空白时间。原文未给结束时仍需按个人计划填写。优先级保持待选择，0必须由用户主动填写；用户反馈的自动0已经增加防误填与确认校验，具体浏览器成因尚待复现。

用“试试九分钟缺口”可加载明确标注的虚构场景，先确认事项，再检查180分钟工作面对9分钟空闲。随后修改剩余分钟，原结果应立即失效；不可拆、最小连续块及依赖等条件尚未排程验证，界面会说明，未发现冲突不代表已排好日程。

## 保存与备份

浏览器维护唯一v2快照。Web Locks加原始字节比对保护跨标签写入；其他标签变化时停自动保存，先导出当前分支再载入最新。无安全保存能力或配额不足时保留当前内存并提示备份，清空与替换有明确确认。导入/导出及v2请求上限一致为15,000,000 UTF-8字节。

空闲未填写是未知；明确点击“确认目前没有可用时间”才按0计算。任务完成后剩余0，恢复需要重新估计。无效输入不进入计算，也不能因其他字段修改而绕过错误。解析、计算和服务连接均保护迟到响应；输出只读，不用服务器的第二份任务覆盖输入。

## 开发测试

保持静态ES模块，无生产构建依赖。开发安装 `npm ci`，运行 `npm test`；jsdom仅为开发依赖，用内存DOM和mock fetch测试事件逻辑，不启动或代替真实浏览器。Node状态与存储测试分别覆盖不可变编辑、门控、锁和分支冲突。Python接口检查在后端运行。

当前自动浏览器被应用保存权限阻止，用户可自行打开预览；代码和DOM测试通过不表示桌面/手机布局视觉验收完成。产品边界见PRODUCT.md，原来源、DSL和阶段记录在父工作区保留。

确认操作会在按钮处显示结果；校验失败定位到首个缺失或无效字段，重复确认不增加修订。静态资产使用index.html中的统一版本（meta、import map、CSS与script查询参数）；修改发布资产时应同步更新该版本并运行npm test，包含根路径和子路径的映射检查。这些静态检查不代替浏览器缓存和渲染验证。

时间精度：新清单和“使用当前时间”按整分钟向后取整，避免计算已过去的秒数；旧清单中的精确起点保留，并在控件旁及计算说明显示实际值。只读空档显示非零秒/小数秒；手动选择日期时间仍以控件所填整分钟为准。当前界面版本2026.10.26.3。

前端2026.10.27.1支持模型候选保留已知固定开始、结束为空，缺结束仍无法确认。只有原文支持可补字段时显示补全入口；后端1.4新增裸日号和星期校验。真实通知人工审阅采集器与合成测试分开，来源不重标为synthetic，详见后端docs/notice_semantics_v1_4.md。

## 提醒、少复制与叠墨权衡（UI 2026.11.10.33–34）

- **提醒**：画卷左栏的铃铛开关（移植自 React Bits 的 BellToggle，原生 JS 实现）。开启后，页面开着时在截止和点墨/约定开始前 30 分钟或 1 小时弹出提醒（允许通知时用系统通知）。网页关掉后无法再提醒，所以“加到手机日历”会导出带闹钟的 `.ics`，交给手机日历响铃。逻辑在 `reminders.js`。
- **少复制几次**：研墨页可一键从剪贴板粘贴、一次选多张截图本机识别；安卓把司序添加到主屏幕后，相册里的截图可直接“分享到司序”（`manifest.webmanifest` + `sw.js` 的 share target，SW 不缓存站点）；iPhone 可用快捷指令打开 `#/import?text=…` 把剪贴板送进砚池。
- **叠墨权衡**：每处叠墨可“请模型权衡”（后端 `/api/v3/advise`，需访问口令），模型只能在规则算好的对策里选；采用“这次不上某门课”后附请假说明草稿。
