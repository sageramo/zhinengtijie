# 司序·知所先后

校园通知与个人任务规划项目，由第7组课程作品「口述行动链」升级。当前本地工作台已提供通知候选、逐项确认、原文依据、真实空闲、剩余时间与修改后重算；旧版Dify对话为独立辅助入口，尚未接入新候选提取流程。公开GitHub Pages/Render未发布本轮改动。

## 本地预览

本目录运行 `../.venv/bin/python -m http.server 8873 --bind 127.0.0.1`，在浏览器打开 `http://127.0.0.1:8873`；后端目录运行 `../.venv/bin/python -m campus_agent.server`，默认8765。前端在localhost自动选择8765，网页不自动发送原文，点击提取或检查时才提交。新前端先验证服务的snapshot_v2能力，不会退回旧服务算法。

用“试试九分钟缺口”可加载明确标注的虚构场景，先确认事项，再检查180分钟工作面对9分钟空闲。随后修改剩余分钟，原结果应立即失效；不可拆、最小连续块及依赖等条件尚未排程验证，界面会说明，未发现冲突不代表已排好日程。

## 保存与备份

浏览器维护唯一v2快照。Web Locks加原始字节比对保护跨标签写入；其他标签变化时停自动保存，先导出当前分支再载入最新。无安全保存能力或配额不足时保留当前内存并提示备份，清空与替换有明确确认。导入/导出及v2请求上限一致为15,000,000 UTF-8字节。

空闲未填写是未知；明确点击“确认目前没有可用时间”才按0计算。任务完成后剩余0，恢复需要重新估计。无效输入不进入计算，也不能因其他字段修改而绕过错误。解析、计算和服务连接均保护迟到响应；输出只读，不用服务器的第二份任务覆盖输入。

## 开发测试

保持静态ES模块，无生产构建依赖。开发安装 `npm ci`，运行 `npm test`；jsdom仅为开发依赖，用内存DOM和mock fetch测试事件逻辑，不启动或代替真实浏览器。Node状态与存储测试分别覆盖不可变编辑、门控、锁和分支冲突。Python接口检查在后端运行。

当前自动浏览器被应用保存权限阻止，用户可自行打开预览；代码和DOM测试通过不表示桌面/手机布局视觉验收完成。产品边界见PRODUCT.md，原来源、DSL和阶段记录在父工作区保留。
